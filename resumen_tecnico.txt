Resumen técnico del proyecto Alfa

1. Descripción general
- Alfa es una aplicación web basada en Laravel destinada a actuar como "colaborador inteligente" para procesamiento de documentos y tareas de IA (OCR, extracción de texto, anonimización, transcripción, extracción de entidades, pruebas LLM). Provee interfaz administrativa, gestión de roles/permisos, y varios microservicios para NLP/Whisper.

2. Tecnologías y frameworks principales
- Backend principal: Laravel (PHP) — ver composer.json: "laravel/framework": "^12.0".
- Lenguaje PHP: objetivo en composer.json "php": "^8.2". Dockerfile usa imagen base "php:8.4-fpm-alpine".
- Frontend: Vite, assets con Bootstrap 5, FontAwesome y AdminLTE; `vite` (vite ^7.0.7) y `laravel-vite-plugin`.
- Sistema de colas/servicios: Supervisor (en Dockerfile) para gestionar procesos en contenedor.
- Contenerización: Docker (Dockerfile y docker-compose.yml presentes). Nginx actúa como reverse proxy (nginx.conf) dentro de la imagen.

4. Arquitectura y componentes principales
- Estructura (carpetas importantes):
  - app/: código principal Laravel (Controllers, Models, Services, Repositories, Providers)
  - resources/views/: vistas Blade (login, layouts, panel administrativo, etc.)
  - database/migrations, seeders: migraciones y seeders (p. ej. menu_items y permisos de menú)
  - public/: assets compilados (public/build si se compila con Vite)
  - nlp_service/, whisper_service/: microservicios Python para NLP y transcripción
  - docker/: scripts y datos para la base de datos y entorno

- Gestión de menú y permisos:
  - Se añadieron `menu_items` (tabla) y permisos `menu.{key}`; la app usa Spatie para asignar esos permisos a roles (p. ej. rol `administrador`).

5. Infra y despliegue
- Dockerfile preparado para instalar Nginx, Supervisor, extensiones PHP y herramientas (tesseract, poppler-utils, etc.).
- Entrypoint y supervisord config proveídos. Exposición en puerto 8080 en la imagen.
- Comandos útiles:
  - Levantar: `docker compose up --build` (o `docker compose up -d --build`)
  - Artisan: `php artisan migrate`, `php artisan db:seed --class=MenuItemsSeeder`, `php artisan view:clear`, `php artisan view:cache`
  - Frontend: `npm install` y `npm run build` (Vite)

7. Seguridad y configuración
- Gestión de roles y permisos con Spatie es la base para habilitar/ocultar entradas de menú y restricciones.
- Variables de entorno: `.env` contiene `APP_MODE` y `APP_DEV_LOGIN` para controlar comportamiento de login (DEV vs PROD).
- Se recomienda revisar `config/permission.php`, `config/app.php` y mantener `permission:cache-reset` tras cambios.

8. Pruebas y calidad
